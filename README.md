Assistant pédagogique en cybersécurité — Jedha

J'ai été assistant pédagogique chez Jedha (bootcamp cybersécurité), après y avoir suivi les parcours Essential et Fullstack.
Ce dépôt rassemble une partie de ce que j'y ai produit.


Mon rôle => épauler les apprenants, pas concevoir le programme. Assistant, pas formateur titulaire.



  Mes missions:
Accompagner les apprenants quand un concept ne passe pas
Corriger les exercices en expliquant pourquoi c'est faux, pas seulement ce qui l'est
Débloquer les labs : diagnostic, pistes, correction
Reprendre un point avec quelqu'un qui décroche, en cherchant un autre angle


  Domaines couverts

Sujets sur lesquels j'ai travaillé

Réseau	SNMP : failles de SNMPv2, migration vers SNMPv3, démonstration avec Wireshark
Réseau (projet final)	Architecture réseau montée de zéro sous GNS3, site mis en ligne, serveur sur solutions gratuites
Cloud	Exercice AWS CreativeFlow : IAM, S3, EC2, application Flask
DevOps / CI-CD	Débogage d'un pipeline : scan Trivy, push vers Docker Hub
Système	Guidage d'un lab SELinux
Sécurité web	Document de correction d'un lab JWT Auth Bypass
Malware	Analyse du ver VBS ILOVEYOU via un lab


Ce que ça m'a appris
Expliquer un concept technique sans le simplifier au point de le déformer
Diagnostiquer vite où quelqu'un est bloqué (souvent un prérequis, pas l'exercice)
Écrire une correction qui apprend quelque chose au lieu de donner la réponse

Ce sont les mêmes réflexes que dans mes missions de conseil : un constat n'a de valeur que si la personne en face le comprend.
